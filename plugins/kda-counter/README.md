# K/D/A Counter

Your kills, deaths and assists against other players, with a sound for every kill.

- **Kills:** a player the game credits to you.
- **Assists:** a player someone else killed, after you hit them in the 15 seconds before.
- **Deaths:** a player killed you.
- **Sound:** each kill in a row plays a higher note, up to six; the sixth is a bright fanfare, and every kill after it adds a twinkle on top (up to five). Assists count toward the streak too, so the next kill is a step higher; only dying ends it. An assist plays the same note, quieter, and a death has its own low sound; both can be turned off in the settings (⚙), with volume and a test button per step.
- **Reset** (↺) clears the counts and the timer.

No names are shown or kept: the meter tells this plugin only that a kill, an assist or a death happened.

Needs a meter with the `kda` event (`events:kda`).
